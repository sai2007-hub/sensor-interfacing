# Sensor Interfacing

## Overview
This repository contains sensor interfacing projects developed using Arduino UNO and ESP32 microcontrollers for learning embedded systems and IoT concepts.

The projects demonstrate:
- Sensor interfacing
- Digital input/output control
- Embedded programming
- Basic automation systems
- Hardware-software integration

---

## Projects Included

### 1. Ultrasonic Sensor Interface
Distance measurement and obstacle detection using ultrasonic sensor.

### 2. LDR Light Detection
Automatic light sensing and LED control using LDR sensor.

### 3. Buzzer Alert System
Audio alert generation for obstacle and signal indication.

### 4. Push Button Interface
Digital input handling using push buttons.

### 5. Sensor-based Automation
Basic automation projects using sensors and microcontrollers.
